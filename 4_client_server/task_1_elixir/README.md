# 4.1 TCP-сервер голосования

Тема: Клиент-серверное взаимодействие  
Язык: Elixir  
Ветка: `4_task_1_elixir`

## Постановка задачи

Требуется написать сервер голосования. Сервер принимает TCP-подключения, каждого клиента обслуживает отдельный процесс. Состояние голосования (варианты и число голосов, список проголосовавших) хранится в GenServer. Клиент может получить список вариантов, проголосовать один раз и посмотреть итоги. После каждого нового голоса текущие итоги рассылаются всем подключённым клиентам.

Входные данные: порт и варианты голосования задаются при запуске сервера, команды клиента вводятся с клавиатуры.

Выходные данные: ответы сервера и текущие итоги голосования у каждого клиента, журнал подключений на сервере.
