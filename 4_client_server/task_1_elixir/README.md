# 4.1 Распределённый подсчёт слов: сервер и клиенты-работники

Тема: Клиент-серверное взаимодействие  
Язык: Elixir  
Ветка: `4_task_1_elixir`

## Постановка задачи

Требуется посчитать частоты слов в большом текстовом файле силами нескольких клиентов-работников. Сервер на `:gen_tcp` читает файл и делит его на части по строкам. Состояние распределения (какие части свободны, какие отданы и кому, какие посчитаны) хранит GenServer. Каждое подключение обслуживается своим процессом. Работник запрашивает задание, получает текст части, считает частоты слов и отправляет результат. Если работник отключился, не сдав часть, она возвращается в очередь. Когда все части посчитаны, сервер сливает результаты.

Входные данные: сервер получает имя файла и размер части аргументами, клиент получает адрес сервера.

Выходные данные: сервер печатает ход распределения и итоговые 20 самых частых слов, каждый клиент печатает, какие части он посчитал.
