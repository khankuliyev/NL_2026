# 4.3 Сетевой аукцион с таймером лотов

Тема: Клиент-серверное взаимодействие  
Язык: Scala  
Ветка: `4_task_3_scala`

## Постановка задачи

Требуется реализовать аукцион по сети на сокетах `java.net`. Сервер читает список лотов со стартовыми ценами из файла и выставляет их по очереди. Клиенты подключаются, вводят имя и делают ставки. Каждый клиент обслуживается в своём потоке, доступ к текущему лоту синхронизирован. Сервер принимает ставку, только если она выше текущей хотя бы на минимальный шаг, и рассылает новую цену и лидера всем клиентам. У лота есть таймер, принятая ставка продлевает его на несколько секунд. Когда время вышло, лот продаётся лидеру и выставляется следующий.

Входные данные: сервер получает порт и файл с лотами, клиент получает адрес сервера, ставки вводятся с клавиатуры.

Выходные данные: клиенты видят текущий лот, цену, лидера и оставшееся время, сервер печатает ход торгов и записывает итоги (лот, покупатель, цена) в файл.
