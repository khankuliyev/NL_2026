# 4.3 Сетевые крестики-нолики

Тема: Клиент-серверное взаимодействие  
Язык: Scala  
Ветка: `4_task_3_scala`

## Постановка задачи

Требуется сделать игру в крестики-нолики для двух игроков по сети. Сервер ждёт подключения двух клиентов, назначает им крестики и нолики и хранит игровое поле. Ходы присылают клиенты по очереди, сервер проверяет, что ход допустим (клетка свободна, сейчас очередь этого игрока), и после каждого хода рассылает поле обоим. Сервер определяет победу или ничью и сообщает результат. Отключение одного игрока завершает партию.

Входные данные: порт задаётся при запуске сервера, адрес сервера при запуске клиента, ходы вводятся с клавиатуры.

Выходные данные: игровое поле и сообщения сервера в консоли клиентов.
