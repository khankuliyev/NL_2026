# 4.2 Файловый сервер на TCP

Тема: Клиент-серверное взаимодействие  
Язык: Erlang  
Ветка: `4_task_2_erlang`

## Постановка задачи

Требуется написать файловый сервер на `gen_tcp`. Сервер раздаёт файлы из указанного каталога, каждое подключение обслуживается отдельным процессом. Клиент может запросить список файлов с размерами и скачать выбранный файл. Перед передачей сервер сообщает размер файла, клиент после приёма проверяет, что получено ровно столько байт. Запрос несуществующего файла и попытка выйти за пределы каталога обрабатываются ошибкой.

Входные данные: каталог и порт задаются при запуске сервера, команды клиента вводятся с клавиатуры.

Выходные данные: список файлов и скачанные файлы у клиента, журнал запросов на сервере.
