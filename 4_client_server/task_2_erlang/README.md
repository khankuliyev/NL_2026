# 4.2 Сервер очереди заданий с повтором при сбое исполнителя

Тема: Клиент-серверное взаимодействие  
Язык: Erlang  
Ветка: `4_task_2_erlang`

## Постановка задачи

Требуется реализовать сервер очереди заданий по TCP (`gen_tcp`) с текстовым протоколом. Клиенты бывают двух видов. Постановщик отправляет задание (разложить число на простые множители) и получает его номер, по номеру может запросить статус и результат. Исполнитель запрашивает очередное задание, выполняет его и сдаёт результат. Каждое подключение обслуживается отдельным процессом, очередь и состояние заданий держит отдельный процесс-диспетчер. Диспетчер следит за процессами исполнителей через `monitor`: если исполнитель отключился, не сдав задание, задание возвращается в очередь.

Входные данные: порт сервера задаётся аргументом, клиент запускается в режиме постановщика или исполнителя, постановщик вводит команды с клавиатуры.

Выходные данные: сервер печатает журнал событий (поставлено, выдано, выполнено, возвращено в очередь), постановщик получает статусы и результаты своих заданий.
