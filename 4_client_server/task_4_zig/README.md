# 4.4 UDP-сервер времени и измерение задержки

Тема: Клиент-серверное взаимодействие  
Язык: Zig  
Ветка: `4_task_4_zig`

## Постановка задачи

Требуется написать UDP-сервер, который на каждый запрос отвечает его порядковым номером и текущим временем, и клиент, работающий как `ping`. Клиент отправляет заданное число запросов с интервалом, ждёт ответ с таймаутом и измеряет время между отправкой и получением. Ответы, не пришедшие за время таймаута, считаются потерянными. Для проверки сервер может отбрасывать часть запросов с заданной вероятностью.

Входные данные: порт и доля отбрасываемых пакетов задаются при запуске сервера, адрес сервера, число запросов и таймаут при запуске клиента.

Выходные данные: время каждого ответа, число потерянных пакетов и процент потерь, минимальная, средняя и максимальная задержка.
