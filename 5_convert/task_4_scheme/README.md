# 5.4 S-выражения в JSON и обратно

Тема: Конвертация данных из одного формата в другой  
Язык: Scheme  
Ветка: `5_task_4_scheme`

## Постановка задачи

Требуется преобразовывать данные из S-выражений в JSON и обратно. Списки становятся массивами JSON, ассоциативные списки вида ((ключ . значение) ...) становятся объектами, числа остаются числами, строки и символы становятся строками, #t и #f становятся true и false. Обратное преобразование разбирает JSON и строит соответствующее S-выражение. Для проверки выражение преобразуется в JSON и обратно и сравнивается с исходным.

Входные данные: направление преобразования, имя входного файла и имя выходного файла задаются аргументами командной строки.

Выходные данные: файл в целевом формате, в режиме проверки сообщение о совпадении или различии.
