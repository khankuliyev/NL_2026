# 5.1 JSON в YAML

Тема: Конвертация данных из одного формата в другой  
Язык: F#  
Ветка: `5_task_1_fsharp`

## Постановка задачи

Требуется преобразовать документ JSON в YAML. Собственный рекурсивный разборщик JSON (без готовых библиотек) строит дерево из объектов, массивов, строк, чисел и литералов true/false/null, обрабатывая экранированные символы в строках. При ошибке в JSON выводится сообщение с номером строки и столбца. Затем дерево печатается в YAML с отступами: объекты как пары ключ-значение, массивы как списки через дефис. Строки, которые в YAML можно спутать с числами или служебными словами, берутся в кавычки.

Входные данные: имя входного JSON-файла и имя выходного файла задаются аргументами командной строки.

Выходные данные: YAML-файл с тем же содержимым.
