# 5.1 BMP-изображение в ASCII-арт

Тема: Конвертация данных из одного формата в другой  
Язык: F#  
Ветка: `5_task_1_fsharp`

## Постановка задачи

Дан несжатый 24-битный BMP-файл. Требуется преобразовать его в текстовое изображение из символов. Заголовок файла разбирается вручную по байтам: проверяется сигнатура, читаются ширина, высота, глубина цвета и смещение данных. Пиксели читаются с учётом того, что строки хранятся снизу вверх и дополняются до кратности 4 байтам. Изображение делится на блоки под заданную ширину (с поправкой на то, что символ выше, чем шире), для каждого блока считается средняя яркость, она переводится в символ из шкалы плотности. Неподходящий формат файла сообщается понятной ошибкой.

Входные данные: имя BMP-файла, ширина результата в символах и ключ инверсии задаются аргументами командной строки.

Выходные данные: текстовый файл с ASCII-артом, размеры исходного изображения и результата в консоли.
