# 5.2 Субтитры SRT в WebVTT со сдвигом времени

Тема: Конвертация данных из одного формата в другой  
Язык: Swift  
Ветка: `5_task_2_swift`

## Постановка задачи

Дан файл субтитров в формате SRT: блоки из номера, строки времени `00:01:02,500 --> 00:01:04,000` и одной или нескольких строк текста. Требуется преобразовать его в формат WebVTT: добавить заголовок, заменить запятую в миллисекундах на точку, перенести теги форматирования. Дополнительно можно сдвинуть все реплики на заданное число миллисекунд (вперёд или назад) и умножить время на коэффициент для смены частоты кадров. Программа проверяет ошибки: неверный формат времени, конец раньше начала, реплики, наложенные друг на друга, отрицательное время после сдвига.

Входные данные: имя входного SRT-файла, имя выходного файла, сдвиг и коэффициент задаются аргументами командной строки.

Выходные данные: файл WebVTT и список найденных предупреждений с номерами реплик.
