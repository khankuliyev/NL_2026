# 5.2 INI в JSON

Тема: Конвертация данных из одного формата в другой  
Язык: Swift  
Ветка: `5_task_2_swift`

## Постановка задачи

Требуется преобразовать файл настроек в формате INI в JSON. Разбираются секции в квадратных скобках, пары `ключ = значение`, комментарии, начинающиеся с `;` или `#`, и пустые строки. Тип значения определяется автоматически: целое или дробное число, булево значение (true/false, yes/no, on/off), строка; кавычки вокруг строки снимаются. Ключи вне секций попадают в корень. Ошибочные строки выводятся как предупреждения с номером строки.

Входные данные: имя входного INI-файла и имя выходного файла задаются аргументами командной строки.

Выходные данные: JSON-файл, где каждая секция становится вложенным объектом.
