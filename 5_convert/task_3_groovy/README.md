# 5.3 Контакты vCard в CSV

Тема: Конвертация данных из одного формата в другой  
Язык: Groovy  
Ветка: `5_task_3_groovy`

## Постановка задачи

Дан файл в формате vCard (версии 3.0), в котором несколько контактов между `BEGIN:VCARD` и `END:VCARD`. Требуется выгрузить контакты в таблицу CSV. Разборщик написан вручную: склеивает строки, перенесённые по правилам формата (продолжение начинается с пробела), отделяет имя поля от параметров (`TEL;TYPE=CELL:...`), разбирает составные поля имени и адреса, снимает экранирование. Если у контакта несколько телефонов или почт, они разносятся по столбцам по типу. Набор столбцов собирается по всем контактам, в CSV экранируются запятые, кавычки и переводы строк.

Входные данные: имя входного файла .vcf и имя выходного CSV задаются аргументами командной строки.

Выходные данные: CSV-файл с первой строкой-заголовком, число обработанных контактов и предупреждения о неразобранных строках в консоли.
