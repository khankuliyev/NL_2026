# 5.3 CSV в HTML-таблицу

Тема: Конвертация данных из одного формата в другой  
Язык: Groovy  
Ветка: `5_task_3_groovy`

## Постановка задачи

Требуется преобразовать файл CSV в HTML-страницу с таблицей. Собственный разборщик CSV (без готовых библиотек) понимает поля в кавычках, запятые и переводы строк внутри полей, удвоенные кавычки. Первая строка становится заголовком таблицы. Строки с другим числом полей дополняются пустыми ячейками. Специальные символы HTML экранируются, числовые столбцы выравниваются по правому краю.

Входные данные: имя входного CSV-файла, имя выходного файла и, при необходимости, разделитель задаются аргументами командной строки.

Выходные данные: HTML-страница с таблицей и минимальными стилями, в консоль число строк и столбцов.
