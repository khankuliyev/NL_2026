# 3.1 Пакетное переименование файлов по шаблону с отменой

Тема: Ввод/вывод в консоль и файл  
Язык: Perl  
Ветка: `3_task_1_perl`

## Постановка задачи

Требуется переименовать группу файлов в каталоге по правилу. Пользователь задаёт регулярное выражение для отбора файлов и шаблон нового имени, в котором можно использовать группы из выражения, порядковый номер с ведущими нулями и дату изменения файла. Сначала программа печатает таблицу «старое имя → новое имя» и проверяет конфликты: одинаковые новые имена или уже существующие файлы. После подтверждения с клавиатуры файлы переименовываются, каждое действие записывается в файл журнала. Отдельный режим читает журнал и возвращает старые имена.

Входные данные: каталог, регулярное выражение и шаблон задаются аргументами командной строки, подтверждение вводится с клавиатуры, режим отмены выбирается ключом.

Выходные данные: таблица предпросмотра в консоли, сообщения о конфликтах, файл журнала переименований.
