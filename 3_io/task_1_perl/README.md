# 3.1 Поиск по регулярному выражению в файлах

Тема: Ввод/вывод в консоль и файл  
Язык: Perl  
Ветка: `3_task_1_perl`

## Постановка задачи

Требуется написать упрощённый аналог утилиты `grep`. Программа ищет строки, подходящие под регулярное выражение, в одном или нескольких файлах. Для каждой найденной строки печатается имя файла и номер строки, совпадения выделяются цветом. Поддерживаются ключи: поиск без учёта регистра, инвертированный поиск и вывод только количества совпадений. Несуществующие файлы не прерывают работу, о них выводится предупреждение.

Входные данные: регулярное выражение, ключи и список файлов задаются аргументами командной строки.

Выходные данные: найденные строки в консоль, сводка по числу совпадений в каждом файле в файл отчёта.
