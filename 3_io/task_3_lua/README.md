# 3.3 Консольная викторина с историей результатов

Тема: Ввод/вывод в консоль и файл  
Язык: Lua  
Ветка: `3_task_3_lua`

## Постановка задачи

Требуется сделать консольную викторину. Вопросы с вариантами ответов и номером правильного варианта хранятся в текстовом файле, программа читает их при запуске и задаёт в случайном порядке. Ответ вводится с клавиатуры, неверный ввод переспрашивается. После игры результат, дата и затраченное время дописываются в файл истории. Из главного меню можно начать игру, посмотреть лучшие результаты или выйти.

Входные данные: файл с вопросами, имя игрока и ответы вводятся с клавиатуры.

Выходные данные: вопросы и итог игры в консоль, история результатов в файл.
