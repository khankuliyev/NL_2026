# 3.2 Форматирование текста по ширине

Тема: Ввод/вывод в консоль и файл  
Язык: Ruby  
Ветка: `3_task_2_ruby`

## Постановка задачи

Дан текстовый файл, абзацы в нём разделены пустыми строками. Требуется переформатировать текст под заданную ширину строки. Абзац разбивается на слова, слова переносятся в следующую строку так, чтобы строка не превышала ширину, слишком длинные слова разрываются с дефисом. Режим выравнивания выбирается пользователем: по левому краю, по правому, по центру или по ширине. При выравнивании по ширине лишние пробелы распределяются между словами равномерно, последняя строка абзаца выравнивается по левому краю. Дополнительно печатается статистика по тексту.

Входные данные: имя входного файла, ширина строки и режим выравнивания задаются аргументами командной строки, если чего-то не хватает, программа спрашивает с клавиатуры.

Выходные данные: отформатированный текст в консоли и в выходном файле, число абзацев, строк и слов.
