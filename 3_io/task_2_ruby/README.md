# 3.2 Построчное сравнение двух файлов

Тема: Ввод/вывод в консоль и файл  
Язык: Ruby  
Ветка: `3_task_2_ruby`

## Постановка задачи

Требуется сравнить два текстовых файла построчно, как это делает утилита `diff`. Для последовательностей строк двух файлов динамическим программированием находится наибольшая общая подпоследовательность. Строки, не вошедшие в неё, считаются удалёнными из первого файла или добавленными во второй. Изменения группируются в блоки с номерами строк.

Входные данные: имена двух сравниваемых файлов и имя файла для результата задаются аргументами командной строки.

Выходные данные: список изменений в консоль (удалённые строки отмечаются `-`, добавленные `+`) и в файл, итоговое число добавленных и удалённых строк.
