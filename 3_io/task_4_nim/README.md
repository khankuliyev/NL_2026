# 3.4 Шифрование файлов шифром Виженера

Тема: Ввод/вывод в консоль и файл  
Язык: Nim  
Ветка: `3_task_4_nim`

## Постановка задачи

Требуется шифровать и расшифровывать файлы шифром Виженера. Шифрование побайтовое: к каждому байту файла прибавляется по модулю 256 соответствующий байт ключа, ключ повторяется по длине файла. Так можно шифровать любые файлы, а не только текст. Работа ведётся через консольное меню: зашифровать, расшифровать, проверить совпадение двух файлов, выйти.

Входные данные: пункт меню, имена файлов и ключ вводятся с клавиатуры.

Выходные данные: зашифрованный или расшифрованный файл, размер обработанных данных и результат проверки совпадения файлов.
