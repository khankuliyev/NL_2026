# 2.4 Кодирование Хаффмана

Тема: Алгоритмические задачи  
Язык: Kotlin  
Ветка: `2_task_4_kotlin`

## Постановка задачи

Требуется сжать текст кодом Хаффмана. Сначала считаются частоты символов, затем с помощью очереди с приоритетом строится дерево Хаффмана: два узла с наименьшей частотой объединяются, пока не останется один. Обходом дерева получается таблица кодов. Текст кодируется в последовательность битов, затем декодируется по дереву обратно.

Входные данные: имя текстового файла задаётся аргументом командной строки.

Выходные данные: таблица частот и кодов символов, размер исходного и сжатого текста в битах, степень сжатия и результат проверки, что декодированный текст совпадает с исходным.
