# 2.2 Калькулятор выражений методом рекурсивного спуска

Тема: Алгоритмические задачи  
Язык: OCaml  
Ветка: `2_task_2_ocaml`

## Постановка задачи

Требуется вычислять арифметические выражения с числами, операциями +, -, *, /, возведением в степень, унарным минусом и скобками. Строка разбивается на лексемы, затем взаимно рекурсивные функции разбора выражения, слагаемого и множителя строят дерево выражения с учётом приоритетов и ассоциативности операций. Дерево вычисляется рекурсивно. При синтаксической ошибке или делении на ноль выводится понятное сообщение с позицией ошибки.

Входные данные: выражения вводятся построчно с клавиатуры, пустая строка завершает работу.

Выходные данные: значение каждого выражения или сообщение об ошибке.
