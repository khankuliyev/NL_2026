# 2.1 Задача о N ферзях

Тема: Алгоритмические задачи  
Язык: Haskell  
Ветка: `2_task_1_haskell`

## Постановка задачи

На шахматной доске N×N требуется расставить N ферзей так, чтобы никакие два не били друг друга. Решение ищется рекурсивно: ферзь ставится в очередную строку на каждую позицию, которая не бьётся уже поставленными ферзями по столбцу и диагоналям, затем функция вызывается для следующей строки. Требуется найти все расстановки.

Входные данные: размер доски N задаётся аргументом командной строки.

Выходные данные: количество найденных расстановок и первая расстановка, нарисованная в виде доски.
