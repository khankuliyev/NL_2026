# 2.1 Генерация и прохождение лабиринта (рекурсия)

Тема: Алгоритмические задачи  
Язык: Haskell  
Ветка: `2_task_1_haskell`

## Постановка задачи

Требуется сгенерировать лабиринт размера W×H и найти в нём путь от входа (левый верхний угол) к выходу (правый нижний угол). Генерация выполняется рекурсивным поиском в глубину: из текущей клетки в случайном порядке перебираются непосещённые соседи, стена до соседа убирается и функция рекурсивно вызывается для него. Случайные числа даёт собственный линейный конгруэнтный генератор, поэтому лабиринт воспроизводится по зерну. Путь ищется отдельной рекурсивной функцией с возвратом из тупиков.

Входные данные: ширина, высота лабиринта и зерно генератора задаются аргументами командной строки.

Выходные данные: лабиринт в виде ASCII-рисунка с отмеченным путём, длина пути и число клеток, посещённых при поиске.
