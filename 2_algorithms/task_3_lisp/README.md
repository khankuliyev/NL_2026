# 2.3 Игра «Числа»: получение целевого числа из набора (рекурсия)

Тема: Алгоритмические задачи  
Язык: Common Lisp  
Ветка: `2_task_3_lisp`

## Постановка задачи

Даны 6 натуральных чисел и целевое число (как в телеигре «Countdown»). Требуется составить выражение из части или всех данных чисел с операциями +, -, *, /, значение которого равно целевому числу. Каждое число можно использовать не больше одного раза, промежуточные результаты должны быть натуральными. Рекурсивная функция выбирает пару чисел, заменяет её результатом операции и вызывает себя для нового набора, вместе с числом хранится выражение, из которого оно получено. Если точного решения нет, выводится самое близкое.

Входные данные: набор чисел и целевое число задаются аргументами командной строки или вводятся с клавиатуры.

Выходные данные: выражение, дающее целевое число (или самое близкое к нему), его значение и число рассмотренных вариантов.
