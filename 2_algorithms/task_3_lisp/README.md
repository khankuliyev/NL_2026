# 2.3 Задача о рюкзаке 0/1 с мемоизацией

Тема: Алгоритмические задачи  
Язык: Common Lisp  
Ветка: `2_task_3_lisp`

## Постановка задачи

Имеется набор предметов, у каждого есть название, вес и ценность, и рюкзак заданной вместимости. Требуется выбрать набор предметов с наибольшей суммарной ценностью, не превышающий вместимость. Рекурсивная функция для каждого предмета рассматривает два варианта: взять его или не брать. Уже посчитанные пары (номер предмета, оставшаяся вместимость) запоминаются в хеш-таблице. После подсчёта по таблице восстанавливается сам набор выбранных предметов.

Входные данные: файл со списком предметов и вместимость рюкзака задаются аргументами командной строки.

Выходные данные: максимальная ценность, суммарный вес и список выбранных предметов, а также число вызовов функции с мемоизацией и без неё для сравнения.
