# 1.4 Параллельное моделирование теплопроводности на пластине

Тема: Многопоточность  
Язык: Julia  
Ветка: `1_task_4_julia`

## Постановка задачи

Дана прямоугольная пластина, разбитая на сетку N×M. На краях пластины поддерживается постоянная температура (например, один край горячий, остальные холодные). Требуется найти установившееся распределение температуры внутри методом Якоби: новое значение в каждой точке равно среднему четырёх соседей на прошлой итерации. Строки сетки на каждой итерации обновляются параллельно через `Threads.@threads`, используются два массива, чтобы потоки не мешали друг другу. Итерации останавливаются, когда максимальное изменение становится меньше заданной точности.

Входные данные: размер сетки, температуры на краях и точность задаются аргументами командной строки, число потоков задаётся при запуске Julia (`-t`).

Выходные данные: число итераций, время работы, итоговое поле температуры в виде изображения в файле PGM (светлее значит горячее).
