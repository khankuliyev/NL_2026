# 1.4 Параллельное построение фрактала Мандельброта

Тема: Многопоточность  
Язык: Julia  
Ветка: `1_task_4_julia`

## Постановка задачи

Требуется построить изображение множества Мандельброта в заданной области комплексной плоскости. Для каждой точки считается число итераций z = z² + c до выхода |z| за 2 или до достижения предела итераций, по числу итераций определяется яркость пикселя. Строки изображения распределяются между потоками через `Threads.@threads`.

Входные данные: ширина и высота изображения, предел итераций и имя выходного файла задаются аргументами командной строки, число потоков задаётся при запуске Julia.

Выходные данные: изображение в формате PGM и время построения для одного и для нескольких потоков.
