# 1.3 Вычисление числа π методом Монте-Карло

Тема: Многопоточность  
Язык: D  
Ветка: `1_task_3_d`

## Постановка задачи

Требуется оценить число π методом Монте-Карло: в единичный квадрат бросаются случайные точки, доля точек, попавших в четверть единичного круга, умноженная на 4, даёт оценку π. Точки делятся между потоками с помощью `std.parallelism`, у каждого потока свой генератор случайных чисел. Нужно исследовать, как точность и скорость зависят от числа точек и числа потоков.

Входные данные: общее число точек и максимальное число потоков задаются аргументами командной строки.

Выходные данные: таблица: число потоков, полученная оценка π, отклонение от точного значения, время работы и ускорение относительно одного потока.
