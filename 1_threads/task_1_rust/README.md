# 1.1 Параллельное умножение больших матриц

Тема: Многопоточность  
Язык: Rust  
Ветка: `1_task_1_rust`

## Постановка задачи

Даны две квадратные матрицы размера N×N, заполненные случайными числами. Требуется вычислить их произведение на нескольких потоках. Строки матрицы-результата делятся между потоками поровну, исходные матрицы потоки только читают и получают через `Arc`, каждый поток записывает свою часть результата. Число потоков задаёт пользователь.

Входные данные: размер матриц N и число потоков задаются аргументами командной строки.

Выходные данные: время умножения на одном потоке и на N потоках, ускорение и результат проверки: совпадает ли многопоточное произведение с однопоточным.
