# 1.1 Параллельный поиск файлов-дубликатов

Тема: Многопоточность  
Язык: Rust  
Ветка: `1_task_1_rust`

## Постановка задачи

Дан каталог с произвольной вложенностью подкаталогов. Требуется найти все группы файлов с одинаковым содержимым. Сначала программа рекурсивно обходит каталог и группирует файлы по размеру, файлы с уникальным размером сразу отбрасываются. Остальные файлы раздаются рабочим потокам `std::thread` через канал `mpsc`, каждый поток читает файл и считает хеш его содержимого, результаты отправляются обратно главному потоку. Файлы с совпавшим хешем дополнительно сравниваются побайтово. Число потоков задаёт пользователь.

Входные данные: путь к каталогу и число потоков задаются аргументами командной строки.

Выходные данные: группы файлов-дубликатов с путями и размером, объём места, который занимают лишние копии, время работы на одном потоке и на N потоках.

## Реализация

- `walk` рекурсивно обходит каталог (символические ссылки и пустые файлы пропускаются), файлы группируются по размеру, файлы с уникальным размером отбрасываются.
- `hash_parallel` запускает N потоков `std::thread`. Задания (индекс, путь) идут к ним через канал `mpsc`, приёмник общий под `Arc<Mutex<_>>`. Каждый поток читает файл блоками по 64 КБ, считает хеш (`DefaultHasher`) и отправляет результат главному потоку через второй канал.
- Файлы с совпавшей парой (размер, хеш) дополнительно сравниваются побайтово, поэтому коллизия хеша не даст ложного дубликата.
- Перед замером делается прогревочный проход, чтобы все файлы были в кеше ОС и сравнение 1 и N потоков было честным.

## Сборка и запуск

Нужен Rust (`cargo`), внешних зависимостей нет.

```bash
cargo build --release
./gen_testdata.sh testdata 300        # тестовый каталог с дубликатами
./target/release/dupfind testdata 8   # каталог и число потоков
```

Если число потоков не указано, берётся число ядер.
