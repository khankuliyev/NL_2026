# 1.1 Параллельный поиск файлов-дубликатов

Тема: Многопоточность  
Язык: Rust  
Ветка: `1_task_1_rust`

## Постановка задачи

Дан каталог с произвольной вложенностью подкаталогов. Требуется найти все группы файлов с одинаковым содержимым. Сначала программа рекурсивно обходит каталог и группирует файлы по размеру, файлы с уникальным размером сразу отбрасываются. Остальные файлы раздаются рабочим потокам `std::thread` через канал `mpsc`, каждый поток читает файл и считает хеш его содержимого, результаты отправляются обратно главному потоку. Файлы с совпавшим хешем дополнительно сравниваются побайтово. Число потоков задаёт пользователь.

Входные данные: путь к каталогу и число потоков задаются аргументами командной строки.

Выходные данные: группы файлов-дубликатов с путями и размером, объём места, который занимают лишние копии, время работы на одном потоке и на N потоках.
