# 1.2 Модель банка на программной транзакционной памяти

Тема: Многопоточность  
Язык: Clojure  
Ветка: `1_task_2_clojure`

## Постановка задачи

Имеется банк с несколькими счетами, состояние каждого счёта хранится в `ref`. Несколько потоков одновременно выполняют переводы между случайно выбранными счетами. Каждый перевод выполняется внутри транзакции `dosync`: если на счёте отправителя не хватает денег, перевод отклоняется. Требуется показать, что при одновременной работе потоков деньги не теряются и не появляются из ничего.

Входные данные: число счетов, начальный баланс, число потоков и число переводов на поток задаются аргументами командной строки.

Выходные данные: общая сумма денег до и после работы потоков, результат проверки их равенства, число выполненных и отклонённых переводов, время работы.
