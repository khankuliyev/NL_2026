# 1.2 Симуляция касс супермаркета на агентах

Тема: Многопоточность  
Язык: Clojure  
Ветка: `1_task_2_clojure`

## Постановка задачи

Требуется смоделировать работу нескольких касс супермаркета. Каждая касса представлена агентом (`agent`) со своей очередью покупателей и обслуживает их по одному, время обслуживания зависит от числа товаров. Генератор покупателей работает в отдельном потоке через `future`, создаёт покупателей со случайным числом товаров и ставит каждого в самую короткую очередь. Общая статистика (число обслуженных, суммарное и максимальное время ожидания) хранится в `atom` и обновляется через `swap!`. Симуляция повторяется для разного числа касс.

Входные данные: число касс, число покупателей и скорость их появления задаются аргументами командной строки.

Выходные данные: для каждого варианта числа касс: среднее и максимальное время ожидания покупателя, число обслуженных каждой кассой и её загрузка в процентах.

## Реализация

- Каждая касса это `agent` с состоянием `{:id :served :busy}`. Покупатель ставится в очередь вызовом `send-off`, а агент выполняет присланные действия строго по одному. Поэтому очередь действий агента и есть очередь к кассе. Действие `serve` ждёт время обслуживания (15 с + 3 с на товар) и обновляет состояние кассы.
- Длины очередей хранятся в `atom` (вектор чисел). Генератор выбирает самую короткую очередь и увеличивает её счётчик одним `swap-vals!`, касса уменьшает счётчик после обслуживания.
- Генератор покупателей работает в `future`. Паузы между покупателями распределены экспоненциально со средним `1/скорость`, число товаров от 1 до 30. Поток покупателей генерируется с фиксированным зерном, поэтому все варианты числа касс получают одних и тех же покупателей.
- Общая статистика (обслужено, суммарное и максимальное ожидание, самая длинная очередь) лежит в `atom` и обновляется через `swap!`.
- Время модельное: 1 секунда модели равна 0.25 мс реального времени, все времена печатаются в секундах модели.
- Симуляция повторяется для 1, 2, ..., K касс.

## Запуск

Нужны Java и Clojure CLI (`clojure`).

```bash
clojure -M -m supermarket.core 7 300 0.1
```

Аргументы: наибольшее число касс K (по умолчанию 5), число покупателей (300), сколько покупателей приходит в секунду (0.1, то есть один раз в 10 с).
